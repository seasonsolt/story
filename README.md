# 冰雪故事小导演

面向 4–6 岁小女孩的纯中文结构化表达启蒙游戏，由艾莎、安娜和雪宝陪伴完成 8 关故事搭建 + 纯本地平板录音回放，支持离线 PWA。

## 4 大结构化表达模块（8 关）
- **时间顺序（第 1–2 关）**：`先 → 接着 → 最后`（一起堆雪宝、烤草莓蛋糕）
- **完整句子（第 3–4 关）**：`谁 → 在哪儿 → 干什么 → 怎么样`（魔法造句列车）
- **总分归类（第 5–6 关）**：先说主题 + `第一 · 第二 · 第三`（野餐甜品篮、保暖小衣柜）
- **因果理由（第 7–8 关）**：`我选…… → 因为……`（小侦探理由桥、盛典许愿灯）
- **扩展玩法**：自由造句小火车、我的故事留声机（纯本地 `MediaRecorder` + `IndexedDB` 零上传）、家长表达力报告与每日亲子提问卡。
